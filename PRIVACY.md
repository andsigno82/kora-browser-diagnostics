# Privacy policy

Kora Browser Diagnostics is designed to prepare selected browser diagnostics in
Kora Desktop on the same machine.

- Capture is opt-in per site or tab.
- The extension does not intentionally collect cookies, passwords,
  authorization headers, or request/response bodies.
- Diagnostics are transferred only to a paired local Kora Desktop bridge.
- Kora prepares a Markdown report and a pending chat reference; it does not
  submit a message automatically.
- A user may revoke browser pairing from Kora.

This policy is a development baseline. Store-specific disclosures will be
published only when the first release's permissions and capture behavior are
final.
